Koneksi Supabase

Jembatan migrasi untuk SATRIA Framework 3.0
Penting: sinkronisasi tahap ini memakai satu snapshot JSON per organisasi untuk menjaga kompatibilitas HTML lama. Semua anggota organisasi yang aktif dapat membaca seluruh data snapshot; pembatasan per OPD belum diterapkan. Gunakan hanya pada staging/pilot setelah meninjau SQL. Skema relasional, Storage, dan RLS granular tetap diperlukan sebelum produksi multi-OPD.
Unduh salinan HTML berkonfigurasi agar URL, anon key, dan UUID tertanam di file. Siapa pun yang menerima file dapat melihat publishable/anon key; akses data tetap wajib dibatasi RLS. Jangan pernah memasukkan `service_role` atau secret key.

Belum terhubung.

Prosedur: siapkan project staging → jalankan file SQL pendamping satria-supabase-staging-bootstrap.sql setelah ditinjau → buat akun Auth → bootstrap organisasi dan membership admin melalui SQL Editor → masukkan URL, publishable/anon key, dan UUID organisasi → login → tarik atau kirim snapshot. Ekspor backup lokal terlebih dahulu. Konflik versi harus diselesaikan dengan menarik versi terbaru; sistem tidak menggabungkan perubahan otomatis.

Persiapan database

SQL bootstrap disediakan sebagai file terpisah dari HTML. Setelah konfigurasi diunduh, file HTML hasilnya akan mengisi kembali Project URL, publishable/anon key, dan Organization UUID secara otomatis. Kata sandi tidak ditanam di file.
